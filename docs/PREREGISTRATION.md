## 4. 처리 절차 (고정)

**표본화와 구간.** f_s = 4096 Hz. 분석 구간은 길이 32초(N = 131072), 간격 16초로 파일 시작부터 놓는다(구간 j는 파일 시각 16j ~ 16j+32초, j = 0…254). 각 구간에서 가운데 16초(8~24초)만 유효하다고 보고 나머지는 버린다(필터 가장자리 오염: PSD 역필터 ±2초와 템플릿 길이 최대 약 2초). 유효 시간은 파일 시각 8~4088초, 4080초다. 사건(2047.4초)은 구간 j = 127의 유효 영역 안에 있다.

**PSD.** 각 구간의 PSD는 그 구간 중심에서 ±256초(512초, 파일 끝에서는 파일 안으로 밀어 넣음)의 자료로 Welch 방법으로 추정한다: 4초 조각, Hann 창, 50 % 겹침, **중앙값** 평균(scipy.signal.welch의 `average='median'`, 편향 보정 포함). 중앙값은 사건이나 glitch 한두 개에 덜 민감하다. 사건이 든 구간도 같은 방식이며 사건을 빼지 않는다. 0.25 Hz 격자의 PSD를 분석 격자(1/32 Hz)로 선형 보간하고, 1/S(f)의 시간 응답을 ±2초로 자른다(inverse spectrum truncation).

**창과 대역.** FFT 전에 Tukey 창(양쪽 1초 taper)을 곱한다. 내적의 적분 범위는 20~1024 Hz.

**matched filter.** 노이즈 가중 내적 ⟨a|b⟩ = 4 Re ∫ ã(f) b̃*(f) / S(f) df. 복소 필터 출력 z(t) = 4 ∫ s̃(f) h̃*(f) / S(f) e^{2πift} df, σ² = ⟨h|h⟩, ρ(t) = |z(t)| / σ. 절댓값을 쓰므로 위상에 대해 최대화된다. numpy FFT로 직접 구현한다. pycbc는 쓰지 않는다.

**템플릿.**
- (a) TaylorF2: 직접 구현. 위상은 [B09] 식 (3.18)의 3.5PN, 무회전, 진폭은 Newton 차수 f^(−7/6), f_ISCO = c³ / (6^{3/2} π G M)에서 끊는다. lalsimulation의 TaylorF2와 위상을 비교하는 단위 테스트를 둔다(구현 확인용, 판정과 무관).
- (b) IMRPhenomD: lalsimulation `SimInspiralChooseFDWaveform`(lalsuite 8.0.2), 무회전, f_min = 20 Hz. 설치가 가능함은 자료를 받기 전에 확인했다.
- 모든 질량은 **검출기 기준**이다.

**템플릿 뱅크.**
- 거친 뱅크(탐색·배경·주입용): m1, m2 ∈ {20, 22, …, 80} M☉, m1 ≥ m2, IMRPhenomD 496개. 무회전.
- 세밀한 뱅크(사건 매개변수용): 거친 뱅크의 최대 network SNR 템플릿을 중심으로 m1, m2 각각 ±6 M☉, 0.5 M☉ 간격, m1 ≥ m2.
- TaylorF2도 같은 두 격자로 돌린다.
- 한계(미리 적음): 실제 탐색의 뱅크(약 25만 개, 질량 1~99 M☉, spin 포함, [S] 7쪽)보다 훨씬 좁고 성기다. 시행 횟수가 적어 배경이 낮게 나오는 쪽으로 유리하다. 뱅크의 최소 match는 측정해서 보고한다.

**사건 측정값의 정의.**
- 템플릿마다 ρ_H(t), ρ_L(t)를 구하고 ρ_net² = max over (t_H, t_L), |t_H − t_L| ≤ 15 ms 인 ρ_H²(t_H) + ρ_L²(t_L). ρ_net이 가장 큰 템플릿이 최적 템플릿이다.
- 보고 값: 최적 템플릿의 ρ_H, ρ_L, ρ_net, 질량, chirp mass, 그리고 도착 시간 차 Δt = t_H − t_L. 정점 시각은 |z| 최대 표본과 양옆 표본의 포물선 보간으로 구한다(표본 간격 0.244 ms).
- 불확도 어림: 세밀한 뱅크에서 ρ_net² ≥ ρ_max² − 4.61 인 템플릿들의 ℳ, M 범위(자유도 2의 90 % profile likelihood 근사). 사후분포가 아니다.
- 원천 기준 값은 ℳ_det / (1 + z), z = 0.09([C])로 환산한다. z를 문헌에서 빌리므로 원천 기준 비교는 검출기 기준 비교와 독립이 아니다.

**merger·ringdown 기여.** 최적 IMRPhenomD 템플릿의 질량에서 세 가지 SNR을 비교한다: (i) IMRPhenomD 전체, (ii) 같은 IMRPhenomD를 f_ISCO에서 자른 것, (iii) TaylorF2(f_ISCO까지). 1 − ρ(ii)² / ρ(i)²를 "f_ISCO 위 대역의 SNR² 비율"로 보고한다. (ii)와 (iii)의 차이는 inspiral 대역 안에서 PN 위상이 어긋나는 정도다. TaylorF2 뱅크 자체의 최대 SNR도 함께 보고한다. 이 항목은 측정만 하고 판정 범위는 두지 않는다. 예상: 검출기 기준 M ≈ 70 M☉이면 f_ISCO ≈ 62 Hz라서 SNR²의 절반 이상이 f_ISCO 위에서 나올 것이다.

**f(t)에서 직접 잰 chirp mass.**
1. 사건 구간을 whitening하고 35~350 Hz Butterworth 4차 대역 통과(앞뒤 두 번, zero-phase)를 건다.
2. matched filter 정점 ±0.1초 안에서 |strain| 최대 시각 t_pk를 잡는다.
3. [t_pk − 0.20 s, t_pk]의 zero-crossing 시각을 선형 보간으로 구한다. 이웃한 crossing 간격 Δt에서 f = 1 / (2Δt), 시각은 두 crossing의 중점.
4. t_pk에서 과거 방향으로 가면서 30 ≤ f ≤ 150 Hz인 점을 차례로 모으고, 범위를 벗어난 점이 처음 나오면 멈춘다.
5. f^(−8/3) = (8π)^{8/3}/5 · (Gℳ/c³)^{5/3} · (t_c − t)를 t에 대한 직선으로 최소제곱 fit하고 기울기에서 ℳ을 구한다. 점이 4개 미만이면 '측정 실패'로 보고한다.
6. H1과 L1을 따로 한다. 판정은 H1(SNR이 더 큼) 값으로 한다. 오차는 fit의 기울기 표준오차를 전파한 값만 적는다.
- 참고용(판정 없음): Q-transform에서 각 시각의 최대 에너지 주파수를 따라간 ridge로 같은 fit.

## 6. 배경과 거짓 경보율 (고정)

1. 각 검출기에서 구간마다 거친 뱅크 496개의 ρ(t)를 구하고, 유효 영역의 각 표본에서 뱅크에 대한 최댓값과 그 템플릿 번호를 남긴다.
2. trigger: ρ ≥ 5.5이고 앞뒤 0.5초 안에서 최대인 표본.
3. 각 trigger에 그 템플릿으로 χ² 검정(Allen 2005, 템플릿 파워가 같은 p = 16개 주파수 대역)을 계산하고, χ²_r = χ² / (2p − 2), [S] 식 (6)으로 재가중한다: χ²_r > 1이면 ρ̂ = ρ / [(1 + (χ²_r)³)/2]^{1/6}, 아니면 ρ̂ = ρ. ρ̂ < 5는 버린다.
4. 동시 발생: |t_H − t_L| ≤ 15 ms. **같은 템플릿을 요구하지 않는다**(뱅크 최댓값만 남기기 때문). PyCBC와 다른 점이며, 배경이 늘어나는 쪽이다. 순위 통계량 ρ̂c = √(ρ̂_H² + ρ̂_L²).
5. zero-lag(이동 없음)에서 ρ̂c가 가장 큰 후보의 시각이 t₀ ± 0.1초이면 "GW150914를 찾았다"고 본다(**B1**).
6. time slide: L1 trigger 시각을 0.1초의 정수배(k = 1 … 40799)만큼 유효 구간 4080초 위에서 원형으로 옮기고 동시 발생을 다시 센다. 배경 시간 T_bg = 40799 × 4080초 ≈ 5.3년.
7. 주 추정에서는 사건 ±1초 안의 trigger를 두 검출기 모두에서 뺀다. 빼지 않은 결과도 함께 보고한다.
8. 사건의 ρ̂c 이상인 배경 후보 수 n. n = 0이면 "FAR < 1 / T_bg"와 포아송 90 % 상한 2.3 / T_bg를 보고한다(**B2**: 사건이 모든 배경 후보보다 큰가).
9. 한계(미리 적음): (a) 자료가 4096초뿐이라 얻을 수 있는 가장 강한 한계가 약 5년에 1번 수준이다. 문헌의 203,000년에 1번은 16일 자료가 있어야 나오는 값이라 재현 대상이 아니다. (b) 이동마다 같은 trigger를 다시 쓰므로 4만 번의 이동은 서로 독립이 아니다. 서로 다른 (H1, L1) trigger 쌍의 수가 실제 정보량이다. (c) 68분 동안의 잡음만 대표한다. (d) 뱅크가 좁다. (e) data-quality veto를 쓰지 않는다.

## 7. 주입 시험 (고정)

- 신호: IMRPhenomD, 무회전, 검출기 기준 (m1, m2) = (38.9, 31.6) M☉. 거리와 무관하게 검출기 기준 질량을 고정한다(실제로는 먼 원천일수록 redshift로 검출기 기준 질량이 커진다. 한계로 적는다).
- 방향과 자세: 하늘 위치 등방, cos ι 균등, 편광각 ψ 균등, 위상 균등. H1, L1의 안테나 패턴 F₊, F×와 도착 시간 차는 검출기 텐서로 직접 계산하고 lal 값과 비교하는 테스트를 둔다. h = F₊ h₊ + F× h×.
- 시각: 사건에서 32초 이상 떨어진 구간을 무작위로 골라 유효 영역 안의 무작위 시각에 넣는다. 구간 하나에 주입 하나.
- 거리: 250, 500, 750, 1000, 1250, 1500, 2000, 2500, 3000 Mpc, 거리마다 100개(난수 seed 고정: 20261115).
- 회수 판정: 6절과 같은 절차(거친 뱅크, 문턱, χ², 동시 발생)로 주입 시각(H1 도착 시각) ±50 ms 안에 동시 발생 후보가 있고 ρ̂c ≥ ρ̂c*이면 '탐지'. **ρ̂c* = 사건을 뺀 time-slide 배경에서 가장 큰 ρ̂c** (즉 FAR ≲ 1/T_bg 문턱). 참고로 ρ̂c ≥ 8 고정 문턱의 곡선도 함께 보고한다.
- 보고: 거리별 효율과 Wilson 68 % 구간, 효율 50 % 거리(선형 보간), 유클리드 부피 적분으로 구한 민감 거리 R = (3/4π · 4π∫ε D² dD)^{1/3}.
- 독립 확인(**C1**): 주입마다 PSD에서 계산한 최적 SNR(σ_H, σ_L)과 회수된 SNR을 비교한다. 최적 network SNR > 10인 주입에서 (회수 ρ_net / 최적 ρ_net)의 중앙값이 0.90 ~ 1.05이면 파이프라인이 정상이라고 본다(뱅크 불일치로 조금 낮고, 잡음으로 흩어진다).
- **C2**: 효율 곡선이 오차 범위 안에서 거리에 대해 단조 감소인가.

## 8. 단위 테스트의 기준 (자료와 무관)

- 내적: 해석적으로 아는 경우(백색 잡음 PSD, 사인파)에서 상대 오차 1e-6 이하.
- SNR 회수: 색 있는 Gaussian 잡음에 알려진 최적 SNR ρ_opt의 템플릿을 넣으면 회수 SNR의 평균이 √(ρ_opt² + 2) 근처이고(잡음 기여), 200회 평균이 표준오차 3배 안에서 맞는다. 잡음만 있을 때 ⟨|z|²/σ²⟩ = 2 ([S] 9쪽).
- 시각 회수: 넣은 시각과 정점 시각의 차이가 1 표본 이하.
- χ²: Gaussian 잡음 속 신호에서 χ²_r 평균이 1 근처, sine-Gaussian glitch에서 1보다 훨씬 큼.
- TaylorF2: lalsimulation TaylorF2와의 위상 차이에서 (상수 + f에 비례하는 항)을 뺀 나머지가 20 Hz ~ f_ISCO에서 0.01 rad 이하.
- time slide: 손으로 만든 trigger 목록에서 동시 발생 수가 직접 센 값과 같다.

## 9. 4단계 (선택): 간단한 매개변수 추정

- emcee, 매개변수는 검출기 기준 (ℳ, q) 둘. spin = 0 고정, IMRPhenomD.
- 가능도: ln L(ℳ, q) = ½ Σ_{d ∈ H1, L1} max_t ρ_d²(t). t의 범위는 2단계 최적 템플릿의 각 검출기 정점 ±5 ms. 진폭과 위상, 도착 시각을 검출기마다 따로 최대화한 profile likelihood다(주변화가 아니다).
- 사전분포: m1, m2에 균등(LVC와 같음) → p(ℳ, q) ∝ ℳ q^{−6/5} (1 + q)^{2/5}, 범위 20 ≤ ℳ ≤ 45 M☉, 0.2 ≤ q ≤ 1.
- 자료: 사건 주변 8초([t₀ − 6, t₀ + 2]), PSD는 4절과 같음. walker 32개, 2000 step, 앞 500 step 버림. 자기상관 시간을 보고한다.
- 판정: **D1** ℳ 중앙값이 문헌 90 % 구간(28.5 ~ 32.5 M☉) 안. **D2** q의 90 % 구간이 문헌 구간(0.62 ~ 0.99)과 겹침.
- 미리 적는 한계: spin을 0으로 고정하고(ℳ–χ_eff 축퇴를 무시), 하늘 위치·거리·기울기를 검출기별 진폭·위상 최대화로 대신하고, 보정 불확도를 넣지 않으므로 구간이 문헌보다 **좁게** 나올 것이다. 좁은 구간을 더 정밀한 측정으로 해석하지 않는다.
- 두 번째 사건(GW151226 등)은 시간이 남을 때만 한다. 하게 되면 그 자료를 받기 전에 이 문서에 판정 범위를 추가로 커밋한다.

## 10. 변경 기록

기준이나 절차를 바꾸면 날짜, 바꾼 내용, 이유, 원래 기준의 결과를 여기에 적는다. 판정 범위(5절)는 바꾸지 않았다.

### 변경 0 (2026-11-15, 자료를 받기 전) — 단위 테스트의 시각 회수 기준을 명확히 함

- 원래 문장(8절): "시각 회수: 넣은 시각과 정점 시각의 차이가 1 표본 이하."
- 문제: 잡음이 있을 때 정점 시각은 대략 1 / (2π ρ σ_f)만큼 흩어진다. 테스트에 쓴 TaylorF2 (30, 30) M☉ 템플릿은 73 Hz에서 끊겨 대역이 좁아서, ρ = 12에서 흩어짐이 1 ms(약 4 표본) 수준이다. 기준이 물리적으로 맞지 않았다.
- 바꾼 기준: 잡음이 없을 때 1 표본 이하. 잡음이 있을 때는 평균 편향이 표준오차 3배 + 0.5 표본 이하이고 표준편차가 3 ms 이하.
- 이 변경은 strain 자료를 받기 전(커밋 67b4896)에 했고, 모의 잡음만 쓰는 테스트에 관한 것이다.

### 변경 1 (2026-11-15, 결과를 본 뒤) — f(t) chirp mass의 zero-crossing 수집 규칙

- **원래 절차의 결과를 먼저 적는다.** 4절 절차 그대로: H1은 점 0개로 **측정 실패**, L1은 점 7개로 ℳ = 35.5 ± 2.5 M☉. 판정 A9는 H1 값으로 하기로 했으므로 **A9는 '재현 안 됨(측정 실패)'**이다. 이 판정은 바꾸지 않는다.
- 실패 원인: 절차 4번이 "t_pk에서 과거로 가면서 30~150 Hz를 벗어난 점이 처음 나오면 멈춘다"인데, H1에서는 t_pk 바로 앞 간격이 156 Hz(merger 구간)라서 첫 점에서 멈췄다. merger 근처 주파수가 150 Hz를 넘는다는 것은 자료와 무관하게 예상할 수 있었으므로 절차 설계의 실수다.
- 바꾼 절차(참고 결과, 판정에 쓰지 않음): t_pk에서 과거로 가면서 f > 150 Hz인 점은 건너뛰고, 처음으로 150 Hz 이하가 된 점부터 원래 규칙대로 모은다. 결과: H1 점 4개, ℳ = 29.2 ± 21.0 M☉(직선 fit의 R² = 0.26, 사실상 측정이 아니다). L1은 원래 절차와 같다(35.5 ± 2.5 M☉).
- 해석: 한 검출기의 whitening한 자료에서 zero-crossing을 그대로 읽는 방법은 잡음이 만든 가짜 crossing 하나에 무너진다. [BP]는 이웃 crossing을 평균하는 등 손질을 했다. 참고용으로 미리 정해 둔 Q-transform ridge fit은 H1 35.9 ± 0.5, L1 39.6 ± 0.5 M☉(오차는 fit 오차뿐)를 준다.
- 절차를 더 손보면 원하는 값이 나올 때까지 고칠 수 있으므로 여기서 멈춘다.
